# Functionalities and Release Priorities

## Version 1 — Trustworthy receipt review

1. Authentication and workspace isolation.
2. Receipt upload with source preservation and duplicate detection.
3. Staged extraction proposal with confidence and evidence, including line items
   when available.
4. Human review, correction, rejection, and approval workflow for receipts and
   manual expenses.
5. Approved purchase list, detail view, and safe source access.
6. Basic search by merchant, product, or receipt ID, plus currency-separated
   summaries.

## Version 2 — Structured purchase intelligence

1. Enhanced merchant, category, product, tax, and payment-method normalization.
2. Near-duplicate review suggestions.
3. Batch upload and review queues.

## Version 3 — Assistance and analytics

1. Spending trends and price comparisons.
2. Configurable automation for trusted receipt sources.
3. Notifications and integrations.
4. Shared or multi-workspace catalog features after privacy review.

Features outside the current release remain proposals until added to the roadmap
with acceptance criteria and a risk assessment.
